# Trivena Builder

Low-code website builder for Trivena Cloud

Based on [frappe/builder](https://github.com/frappe/builder).

## Install

```bash
bench get-app https://github.com/TrivenaCloud/trivena-builder --branch main
bench --site <site> install-app builder
```

## Trivena Cloud

Published on the Trivena Cloud marketplace.
